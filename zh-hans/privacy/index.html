隐私政策

最后更新：2026年10月10日

mybackhurts 是 Vlad Mihalachi 开发的 macOS 和 Windows 应用。本政策说明应用会如何处理你的信息。

应用会处理什么

当你选择摄像头模式时，应用会使用你的摄像头来检测身体姿态并统计动作次数。在 Mac 上，它使用 Apple 的 Vision 框架；在 Windows 上，它使用通过 Windows ML 在你的电脑上运行的姿态模型。在这两个平台上，视频画面和姿态数据都只在你的设备上于内存中处理，并会立即丢弃。应用不会录制、上传或存储图像或视频。摄像头模式是可选的；在简易模式下，除非你主动要求，摄像头会一直保持关闭。

为了不让提醒打扰到你，应用会检查你上次使用键盘或鼠标已过去多久、是否有其他应用正在使用摄像头或麦克风（例如在通话期间），以及是否有全屏应用处于打开状态。它只是从操作系统读取这些状态，从不会打开摄像头或麦克风，也不会保留这些信息。

应用会存储什么

应用会把设置和练习结果（例如动作名称、次数、时长和日期）存储在你设备本地。它不需要账号，也不会收集你的姓名、电子邮件地址、位置、通讯录或浏览活动。

共享与网络访问

mybackhurts 不运营分析、广告、追踪或后端服务，自身也不发起任何网络请求。如果你购买支持者解锁或打赏，该交易由你获取本应用的商店处理：在 Mac 上，Apple 依照其条款和隐私政策，通过 StoreKit 处理；在 Windows 上，Microsoft 依照其条款和隐私声明，通过 Microsoft Store 处理。Windows 版本也通过 Microsoft Store 安装和更新。

保留与删除

你的本地设置和练习记录会一直保留在你的设备上，直到你使用应用中的功能删除它们、移除应用数据或卸载应用。如有隐私方面的问题，可以联系 hello@mybackhurts.app。

变更

当应用或适用的要求发生变化时，我们可能会更新本政策。上方的日期表示最近一次修订的时间。
